Set GOOGLE_PLACES_API_KEY securely in your server environment. Enable Places API (New), billing, and restrict the key to the Places API. Discovery returns business names, websites, addresses and phone numbers; verify email addresses separately.

Hostinger Mail

Set SMTP_HOST, SMTP_PORT, SMTP_USER and SMTP_PASS in the server environment. Use your mailbox password or an app password if supported. The default is smtp.hostinger.com with port 465 and TLS. Confirm these settings in Hostinger. Credentials never belong in chat or source control.

Restart the server after changing environment variables. A configured connection still requires a successful live request. See README.md for deployment and network requirements.
